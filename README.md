# Transistörlü Analog Piyano Projesi 🎹

Bu proje; hazır entegreler (555 zamanlayıcı vb.) veya mikrodenetleyiciler **kullanılmadan**, tamamen saf analog bileşenlerle tasarlanmış bir piyano devresidir. Kare dalga sinyalleri transistörler ve kapasitörler yardımıyla üretilmiştir.

## 🚀 Proje Özellikleri
- **Saf Analog Tasarım:** Herhangi bir entegre veya yazılım (kod) barındırmaz.
- **Özel Kare Dalga Üretimi:** Astable Multivibrator prensibi temel alınarak transistörler üzerinden kendi sinyalini üretir.
- **Ses Çıkışı:** Pasif buzzer kullanılarak farklı frekanslarda (notalarda) ses elde edilmiştir.

## 🛠️ Kullanılan Bileşenler
- Transistörler
- Kapasitörler (Kondansatörler)
- Pasif Buzzer
- Dirençler ve Butonlar
